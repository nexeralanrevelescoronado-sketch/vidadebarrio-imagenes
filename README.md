# vidadebarrio-imagenes

Fotos optimizadas (WebP, sin metadatos) del blog **Vida de Barrio**, servidas con GitHub Pages.

- Las direcciones son `https://nexeralanrevelescoronado-sketch.github.io/vidadebarrio-imagenes/<carpeta>/<archivo>.webp`
- `imagenes.json` lista cada imagen con su ancho, alto, peso y texto alternativo.
- Todas las fotos son del autor del blog y se publican con su permiso.
